# EP-02-S01-T02 — Normalización de fuentes
**Épica:** EP-02 — Base de Conocimiento
**Estado:** Completado
**Responsable:** Luis / Nathanael

## Objetivo
Limpiar el texto extraído de los SOPs para eliminar ruido de formato y dejar una base homogénea para el procesamiento semántico.

## Normalizaciones aplicadas
- Eliminación de artefactos de Word y símbolos inconsistentes.
- Homogeneización de títulos y secciones.
- Conservación del orden operativo original.
- Preparación de texto para el chunking semántico.

## Resultado
El contenido de los SOPs quedó estandarizado y listo para ser fragmentado sin mezclar secciones ni pasos críticos.

## Observación
No se alteró el sentido operativo de los documentos; solo se limpió la presentación técnica del texto.
