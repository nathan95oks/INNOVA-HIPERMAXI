# EP-02-S01-T03 — Etiquetado de secciones por SOP
**Épica:** EP-02 — Base de Conocimiento
**Estado:** Completado
**Responsable:** Luis / Nathanael

## Objetivo
Identificar y etiquetar las secciones relevantes de cada SOP para facilitar la recuperación semántica y el ensamblado de contexto.

## Etiquetas consideradas
- Código del SOP
- Título del documento
- Pasos del flujo
- Actores involucrados
- Errores frecuentes
- Condiciones de escalamiento

## Resultado
Cada SOP quedó organizado con una estructura interna más clara, útil para chunking, búsqueda y respuesta conversacional.

## Nota
Las etiquetas se usan como apoyo técnico interno y no se exponen al proveedor final.
